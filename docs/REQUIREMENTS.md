# Requirements

## Functional

- Local admin login
- Dashboard summary of spend and sync health
- Transactions list and detail views
- Receipt upload for transactions
- Expense category assignment updates
- Expense category listing and creation
- Manual and scheduled sync from Extend

## Non-functional

- Local-first deployment
- Session-protected backend
- Do not expose Extend credentials to the frontend
- Preserve Extend git history in this repo
- Keep AI template integration isolated and maintainable
